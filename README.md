Trabalho de organização de computadores, disiplina da Universidade Estadual do Rio Grande do Sul. Processador 16 bits baseado no mips.
- topo.vhd -> corresponde ao datapath
- memory.vhd -> corresponde à memória de instruções
- data_memory.vhd -> corresponde à memória de dados
- control_unit.vhd -> corresponde à unidade de controle
- inc.vhd -> corresponde ao bloco de incremento e atualização de jumps do program counter
- register_bak.vhd -> corresponde ao banco de registradores
- testbench.vhd -> é o test, bloco que atribui valor ao clock e ao reset a cada 5ns.
